# graphflow-web

Placeholder for the GraphFlow web app. The web app is **not** in scope for
v0.1; see [`docs/roadmap.md`](../../docs/roadmap.md) (v0.3).

When implemented, it will be a thin client that talks to `graphflow-api`
over HTTP. It must not call `graphflow_core` directly.

## Planned tooling (subject to change)

- Node.js 20+
- pnpm
- React + TypeScript
- TailwindCSS
- Lucide icons
